Small marks drawn in ink in place of text glyphs that phones turn into emoji: tick, cross, play, mourning cross, pause and turn back.

Hand-written from `frontend/src/components/shared/InkMarks.jsx`. The same marks are in the Icons asset group as SVG files.

## Rules
- Each takes the text's own color (`currentColor`) and sits on its baseline.
- Never use ▶, ✓, ✔, ✝, ⚠, ★ or ♥ as a mark (The Ink Marks Rule).
- Decorative: the words beside a mark carry the meaning.
- A done state is a pen tick in `seal-green` on paper or `seal-green-lit` on night.
