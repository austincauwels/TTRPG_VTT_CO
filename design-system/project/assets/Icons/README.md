# Icons

Marks drawn in ink (`frontend/src/components/shared/InkMarks.jsx`), standing in for text glyphs that phones turn into emoji. In the app each takes `currentColor`; these files are inked in `ink` (#1a1311) for use on paper. On a dark ground, inline the path and color it `cream`, `seal-green-lit` or `stage-chrome` instead.

- `tick.svg`: a pen tick, done or confirmed.
- `cross.svg`: a pen cross, removed or refused.
- `play.svg`: go in (a campaign you run).
- `mourning-cross.svg`: the death notice.
- `pause.svg`: a timer standing part way.
- `turn-back.svg`: reset to the start.
- `seal-candle-holder.svg`: the mark pressed into the wax seal, in `material-wax-mark` (#641010). GiCandleHolder from game-icons.net, CC BY 3.0, via react-icons.

Everything else in the app's iconography is Game Icons (`react-icons/gi`, CC BY 3.0), drawn at the text's size in its color. No emoji anywhere.
