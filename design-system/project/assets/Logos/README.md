# Logos

The app has no logotype file. Its mark is a lit candle drawn in code on the night stage (`frontend/public/favicon.svg`): a `candle-gold` flame with a `cream` core and a soft gold halo, a `parchment` candle with a `cream` drip, an `ink` wick and an `oxblood` holder, on a 4px-rounded `night` square.

- `candle-mark.svg`: the browser icon. Full color; it carries its own `night` ground, so place it on any surface.
- `candle-mark-touch.png`: the 180 by 180 render for phone home screens.

The wordmark is type, not a file: CANDELA OBSCURA set in the `display` style (Cinzel 400, uppercase, 0.1em tracking), `cream` on `stage`.
